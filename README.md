# OpenSweet OS

> **Хардкорная монолитная 64-битная операционная система на чистом ассемблере x86_64 (Flat Assembler / FASM).**  
> Духовный наследник KolibriOS и MenuetOS в мире современного 64-битного железа Long Mode.  
> **Zero C. Zero Rust. Zero external runtimes.** 100% ручной bare-metal x86_64 ассемблер от первого сектора MBR до графического оконного менеджера и PNG-декодера.

---

## Позиционирование проекта

- **Честный и бескомпромиссный x86_64**: Мы намеренно выбросили из роадмапа нереалистичные обещания про ARM, RISC-V или микроконтроллеры. Это монолитное ядро пишется на чистом x86_64 ассемблере ради удовольствия от низкоуровневого программирования, абсолютного контроля над каждым байтом и регистрами, а также предельной скорости на ПК.
- **Никаких сторонних библиотек и "портирований"**: В ядре нет сторонних сишных библиотек вроде LVGL или littlefs. Каждый алгоритм — оконный менеджер, альфа-композитор, векторный курсор, динамический аллокатор кучи, драйвер ext4 и алгоритм Deflate/zlib для PNG — написан с нуля на FASM.
- **Zero Bloat & Instant Boot**: Мгновенный холодный старт за миллисекунды. Весь образ системы вместе с графической подсистемой, 2D-композитором, шрифтами, драйверами и встроенными приложениями занимает меньше 1.44 МБ и загружается как единый монолит.

## Архитектура и что уже РЕАЛЬНО работает

### 1. Загрузка и инициализация процессора
- **2-стадийный загрузчик**:
  - `arch/x86_64/boot/boot.asm`: MBR boot-сектор (512 байт, loaded at `0x7C00`), чтение Stage 2 через BIOS INT 13h Extensions (LBA-пакет).
  - `arch/x86_64/boot/stage2.asm`: Сбор карты памяти BIOS E820, переключение видеорежима VBE Linear Framebuffer (1080p 32bpp), вход в Protected Mode (32-бит) и прыжок в Long Mode (64-бит).
- **Higher-Half ядро (`0xFFFF800000010000`)**:
  - 4-уровневые таблицы страниц PML4 / PDPT / PD / PT.
  - Identity-маппинг первых 4 ГБ физической памяти для прямого обращения к регистрам устройств, MMIO и видеобуферу.
  - Высокий маппинг ядра в пространстве высшей половины памяти (`PML4[256]`).

### 2. Управление памятью
- **PMM (Physical Memory Manager)**:
  - Парсер дескрипторов BIOS E820.
  - Битмап-аллокатор физических страниц 4 КБ с быстрым поиском свободных блоков.
- **VMM (Virtual Memory Manager)**:
  - Динамическая аллокация таблиц трансляции страниц по требованию (`vmm_map`, `vmm_unmap`).
- **Kernel Heap (Динамический аллокатор кучи)**:
  - Реализация `kmalloc`, `kzalloc`, `kfree`, `krealloc`.
  - Boundary-tag дескрипторы, расщепление блоков (splitting) и слияние соседних свободных фрагментов (coalescing).
  - Автоматическое расширение кучи за счёт страниц физического PMM.

### 3. Прерывания и таймеры
- **64-битная IDT (Interrupt Descriptor Table)**:
  - Обработчики процессорных исключений 0–31 (Page Fault, General Protection Fault, Divide Error и др.) с дампами регистров CR2, RIP, RSP и кода ошибки.
- **Local APIC & PIC**:
  - Переназначение 8259 PIC.
  - Аппаратная инициализация Local APIC, LVT Periodic Timer (1 кГц) с полным сохранением контекста прерываний.

### 4. Вытесняющая многозадачность (Scheduler)
- Превентивный планировщик задач с квантованием по прерываниям APIC таймера.
- Структуры TCB (Task Control Block), переключение контекста регистров, фоновые демоны ядра.

### 5. Драйверы оборудования
- **ATA PIO (IDE)**: LBA28 блочный драйвер жесткого диска (Primary / Secondary master/slave), чтение и верификация секторов.
- **PS/2 мышь и клавиатура**: Прерывистые драйверы (IRQ1, IRQ12), декодирование 3-байтовых пакетов мыши, отслеживание кнопок и относительных дельт X/Y.
- **COM1 UART**: Драйвер последовательного порта (115200 бод) для структурированного логгирования ядра.

### 6. Нативная файловая система ext4 (Pure ASM Read-Only VFS)
- Полноценный драйвер ext4, написанный целиком на FASM (`fs/ext4/ext4.inc`):
  - Парсинг Superblock (`magic = 0xEF53`), проверка флагов совместимости.
  - Чтение таблицы дескрипторов групп блоков (Block Group Descriptors / GDT).
  - Индексация и поиск по Inode Table.
  - Декодирование дерева экстентов (Extents Tree — leaf и index узлы) для чтения фрагментированных файлов.
  - Линейный обход каталогов и чтение файлов по путям.

### 7. Графическая подсистема (32bpp Micro-GUI) и Оконный менеджер
- **Linear Framebuffer**: 1920x1080 @ 32bpp TrueColor с двойной буферизацией в ОЗУ (Backbuffer).
- **Damage Rect Tracking (Грязные прямоугольники)**:
  - Выборочная перерисовка поврежденных участков экрана вместо полного бэкбуфера.
  - Высокий и стабильный FPS при перемещении окон и анимациях.
- **2D-композитор**:
  - Аппаратно-оптимизированный альфа-блендинг (ARGB 32bpp).
  - Сглаженные скругленные прямоугольники (anti-aliased rounded rects), мягкие тени (drop shadows), стеклянные панели.
  - Субпиксельный сглаженный векторный курсор мыши.
  - Шрифтовые движки (растровые и сглаженные моноширинные/UI шрифты).
- **Window Manager (WM)**:
  - Стек окон, управление Z-order (активное окно поверх остальных).
  - Плавное перемещение окон мышью с быстрым сохранением и восстановлением фоновой поверхности (drag surface blitting).
  - Кнопки управления окнами, фокус, нижняя панель приложений (Dock), верхняя строка состояния (Topbar).
- **Встроенный нативный декодер PNG**:
  - Парсинг формата PNG (чанки IHDR, IDAT, IEND).
  - Реализация алгоритма zlib / Deflate (декодер Хаффмана, LZ77 скользящее окно) на чистом ассемблере x86_64.
  - Сканлайн-фильтры (Sub, Up, Average, Paeth) и прямая отрисовка обоев рабочего стола.

### 8. Настоящие системные приложения (без фейков!)
- **Ext4 Explorer (`gui/app_files.inc`)**: Реальный графический файловый менеджер, считывающий каталог ext4-диска в реальном времени, отображающий реальные имена файлов, размеры из экстентов и номера инодов.
- **System Monitor (`gui/app_sysmon.inc`)**: Реальный системный монитор с живыми метриками: опрос PMM (свободные/занятые фреймы ОЗУ), статистика Kernel Heap, CPUID вендор процессора, тики APIC таймера и динамический индикатор прогресса памяти.
- **Terminal Shell (`gui/app_term.inc`)**: Интерактивная терминальная сессия с консольными командами (`help`, `mem`, `heap`, `heaptest`, `tasks`, `ticks`, `ata`, `ls`, `cd`, `cat`, `stat`, `gui`).

## Сборка и запуск

### Требования
1. **FASM** (Flat Assembler 1.73+).
2. **QEMU x86_64** (`qemu-system-x86_64.exe`).
3. Windows 10/11 (cmd / PowerShell).

### Компиляция
```cmd
build.cmd
```
Скрипт компилирует `boot.asm`, `stage2.asm`, `kernel.asm` и упаковывает монолитный образ `build\os.img`.

### Создание диска ext4
```cmd
make-disk.cmd
```
Генерирует тестовый диск `build\disk.img` с реальной файловой системой ext4, деревом экстентов и тестовыми файлами.

### Запуск в QEMU
```cmd
run.cmd
```
Запускает систему в разрешении Full HD с подключенным ext4-диском и выводом системных логов ядра в `build\serial.log`.
